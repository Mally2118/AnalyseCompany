## Модели и воспроизводимость

Основная рыночная регрессия строится по ценовым логарифмическим доходностям на **одинаковых интервалах календаря IMOEX**:

```text
r_t^T = α + β_M r_t^IMOEX + ε_t
r_t = ln(P_t / P_(t−1))
```

Для остановки 2024: α = -0.001344040824, β IMOEX = 1.335799108351; R² обучения = 0.305271. Коэффициенты оцениваются на 252 интервалах 2023-02-20 — 2024-02-15. Это дневной/синхронный торговый масштаб, не годовой темп прибыли.

Контрольная модель — линейная интерполяция **логарифма цены**:

```text
ln(P̂_(L+k)) = ln(P_L) + (k/N) × [ln(P_R) − ln(P_L)]
```

Расширенный кандидат добавляет лог-доходность SBER. Коэффициенты оцениваются совместно; VIF должен быть ≤5 во всех validation-окнах. VIF — заранее выбранный диагностический порог, а не доказательство независимости факторов. SBER **не включён**: validation-ошибка ухудшилась, несмотря на чуть более высокий R² обучения.

Для внутреннего пропуска регрессионная траектория согласуется с обоими краями:

```text
δ = [ln(P_R / P_L) − Σ r̂_j] / N
P̂_(L+k) = P_L × exp(Σ_(j=1..k)(r̂_j + δ))
```

Опоры: 2024-02-15 — 305,700 ₽; 2024-03-18 — 306,700 ₽. Интервалов N = 20; δ = 0.000882985267.

Выбор спецификации для остановки 2024 также ретроспективен: validation до 2025 включает даты после исследуемого пропуска. Коэффициенты именно этого моста при этом оценены только на данных до 15.02.2024.

Постоянная α при этой равномерной поправке алгебраически сокращается: она описывает исходную регрессию, но не создаёт дополнительный дрейф моста. Траектория использует будущую правую фактическую цену. Это **ретроспективное сглаживание**, не прогноз, доступный инвестору во время остановки. Условные цены не подтверждают возможность покупки, продажи или ребалансировки.

## Хронологическая проверка

Проверяются детерминированные скрытые блоки по 3/10/20 синхронных торговых дней с IMOEX. Каждое обучение использует только прошлые данные одного режима, максимум 252 интервала; для проверочного окна требуется минимум 80. Дополнительные выходные торги акциями не создают фиктивные наблюдения индекса. Доходности факторов и акции всегда имеют одинаковые даты границ; нет сжатия нескольких пропущенных дней в один обычный дневной доход. Интервалы длиннее 7 календарных дней и переходы между исследовательскими режимами исключены из обучения, не из основной исторической статистики.

Четыре режима: до кризиса 2022; после возобновления 2022 до редомициляции; март–август 2024; новый периметр с сентября 2024. Последняя граница — явная исследовательская группировка, а не оценённая дата структурного разрыва. Экстремальные наблюдения внутри режимов не обрезаются. Для кризисного разрыва марта 2022 оценка не строится.

**Validation: 36 блоков до 2025 года. Test: 15 блоков 2025 года.** Выбор сделан по средней относительной RMSE на validation, а не по test. Блоки могут перекрываться; их ошибки не независимы. Средняя RMSE по блокам не равна RMSE единого объединённого массива. Рубли приведены к базе сплита 1:10.

| Проверка   | Метод               | MAE, ₽ | RMSE, ₽ | Относительная RMSE |
| ---------- | ------------------- | -----: | ------: | -----------------: |
| validation | Интерполяция log(P) | 10,464 |  12,183 |              3,02% |
| validation | IMOEX               |  9,279 |  10,900 |              2,74% |
| validation | IMOEX + SBER        |  9,324 |  11,084 |              2,79% |
| test       | Интерполяция log(P) |  5,849 |   6,811 |              2,16% |
| test       | IMOEX               |  4,544 |   5,619 |              1,77% |
| test       | IMOEX + SBER        |  3,451 |   4,173 |              1,32% |

На test модель IMOEX + SBER оказалась лучшей. Это открыто показано, но результат test не использован для смены победителя: иначе test превратился бы в дополнительный этап подбора. Выбранная однофакторная модель также превосходит простую интерполяцию на test.

### Остатки и устойчивость

Остатки выбранной модели: σ = 0.016053, lag-1 = -0.1885, Durbin–Watson = 2.3698; асимметрия 0.6438, куртозис 5.8638, Jarque–Bera p = 3.32e-23.
β на двух половинах обучения: 1.2004 → 1.5717. Коэффициент не постоянен. 95%-интервал β с HAC/Newey–West, 5 лагов: [1.0305; 1.6411].

Интервал восстановленной **цены не заявляется**: остатки ненормальны и зависимы, а распределение ненаблюдаемой цены при корпоративной остановке неизвестно. Интервал коэффициента не выдаётся за ценовой интервал. ARIMA и Калман не добавлены: необходимость усложнения и преимущество таких моделей не установлены.

Добавлены **два самостоятельных месячных интервала**: январь→февраль и февраль→март 2024. Двухмесячная доходность не трактуется как месячная. Средние и ковариации меняются у обеих акций, поскольку изменяется общая выборка, даже при полностью фактических ценах SBER. CAGR фактических начальной и конечной стоимостей не меняется. Исследование не создаёт исполнимую ребалансировку при отсутствии торгов.

Для периода 2023–2025 число пар растёт с 34 до 36. При полной доходности минимальный риск в общей выборке меняется с 67% SBER на 66%; основной портфель остаётся 67%, так как это отдельный эксперимент. Все четыре комбинации периода и типа доходности сохранены в [recovery-sensitivity.json](examples/recovery-sensitivity.json). Неизвестные дивиденды не оцениваются: используется только существующий проверенный календарь выплат и прежняя граница доступности полной доходности.

## Позитивный прогноз

Параметры не изменены: T — рост EPS 35% → 15%, P/E 7, payout 30%; Сбер — 15% → 8%, P/E 5, payout 50%. Более высокая доходность T получается из более агрессивного роста EPS, разового перехода к более высокому P/E и дивидендов. Переоценка первого года не повторяется автоматически. Позитивный сценарий прямо назван **оптимистичным учебным стресс-тестом**, без вероятностей. Восстановление биржевой траектории не оценивает EPS и не обосновывает эти параметры. Исторический CAGR не заменён ни рыночной регрессией, ни сценарием.

`recovery:fetch` использует curl и MOEX ISS с пагинацией; сеть нужна только для этой команды. Не меняет market.json. Если обнаружены новые фактические котировки или пересмотр известных свечей, прекращает работу для проверки корпоративной базы; не заменяет опубликованное исследование недостоверным результатом. Запись файлов атомарная. Новый неаудированный пропуск также останавливает построение.

## Проверки и ограничения

- `npm run recovery:check`: Python-расчёт воспроизводится из опубликованных источников, допуск чисел 1e−8; проверка добавлена в CI и workflow публикации. NumPy/pandas/statsmodels/SciPy закреплены в requirements.
- `npm run data:validate`: исходные данные, схема и происхождение восстановления, календарь, счётчики, разделение обучения/проверки, хеши исходного рынка и факторов.
- `npm test`: 98 тестов в семи файлах; в том числе независимое воспроизведение OLS, R², MAE/RMSE и 19 оценок в TypeScript, сохранение фактов, отсутствие повторного сплита, LEGALCLOSEPRICE против CLOSE, два отдельных месяца, края 0/100%, экспорты.
- `npm run build`: TypeScript strict и Vite; 77 файлов offline-кэша.
- `npm run test:e2e`: 15 production-сценариев, включая пунктир и подсказку, масштаб участка, исследовательский переключатель, неизменность фактических KPI, возврат к основному портфелю, защиту от устаревшего JSON, PDF/XLSX/CSV, обе темы и мобильную версию.

Модель не показывает истинную ненаблюдаемую цену остановленного инструмента. Корпоративные новости, редомициляция, ограничения владения и интеграция Росбанка могут менять связь с рынком. Правый якорь известен позже, параметры нестабильны, средние ошибки торговых блоков не являются доверительным интервалом остановки. Сглаживание меняет волатильность и корреляцию; ни заполнение, ни улучшение метрик не доказывают инвестиционную привлекательность и не меняют будущие финансовые сценарии.

Production-сборка готовится для GitHub Pages; backend и платные API не добавлены. README не редактировался. Публикация выполняется существующим workflow после отправки изменений в main/master. Удалённый деплой этой локальной проверкой не подтверждается.
