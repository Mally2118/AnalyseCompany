Результаты можно воспроизвести `npm run data:validate`; данные не извлекаются из графиков или заранее написанных выводов.

## Проверенные источники

Исследовано девять PDF, включая консолидированную МСФО Сбера и Т за 2025. URL, размеры и SHA-256 находятся в `docs/source-audit.json`. Для чисел в `financial.json` сохраняется паспорт источника. В наборе 107 подтверждённых финансовых значений, 23 поля `null`.

MOEX: 1 339 дневных дат, 975 перекрывающихся наблюдений TCSG/T; отношение цен соответствует сплиту 10:1 с ошибкой менее 10⁻⁶. В данных присутствуют реальные паузы и несовпадающие даты. CORS проверен HTTP GET с Origin. Полного автоматически гарантированного доступа ко всем внешним HTML-страницам не заявляется: некоторые страницы Сбера ограничены TLS/антибот-защитой; используемые PDF получены, альтернативные источники отмечены.

Повторный `npm run data:update` успешно сохранил кандидата вне `public/`; все дневные и месячные цены совпали с опубликованным снимком. Отдельный тест имитирует отказ MOEX и подтверждает неизменность `market.json` и raw-истории.

## Границы проверки

- Реальный deployment в GitHub не запускался: удалённый репозиторий не задан. Проверены production-сборка и её обслуживание в произвольной папке, workflow подготовлен для GitHub Pages.
- PDF создаётся через стандартную печать браузера. Пользователь выбирает «Сохранить как PDF». В тесте дополнительно проверен настоящий PDF-файл с кириллицей и графиками.
- XLSX прочитан обратно, проверены формулы и кэшированные значения. Настольные Excel/LibreOffice автоматически не запускались. После редактирования входов в Excel таблица оптимумов и эффективный фильтр остаются снимком, что описано в README.
- Невозможно подтвердить точную фактическую рублёвую полную доходность T за 2021 без проверенного курса и зачисления USD-дивиденда. Она не показывается.
- Часть раскрытой ROA и CIR отсутствует в выбранных документах. Пропуски сохранены. Расчётная ROA на средних годовых активах обозначена отдельно.
- Начальные сценарии — учебные допущения; ретроспективная модель использует EPS 2025, раскрытую в 2026, и не считается прогнозом, доступным на 31.12.2025.
