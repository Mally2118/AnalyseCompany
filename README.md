# AnalyseCompany - Инвестиционная аналитика

Веб-приложение для сравнительного анализа Сбербанка и Т-Технологий за 2021–2025 годы. Финансовые показатели, доходность и риск акций, оптимизация портфеля по модели Марковица, коэффициент Шарпа и сценарное прогнозирование инвестиций.

**Открыть сайт:** [InvestAnalytics](https://mally2118.github.io/AnalyseCompany/).

Приложение использует финансовую отчётность по МСФО и исторические котировки Московской биржи. Доступны инвестиционный калькулятор, сравнение компаний, справочник финансовых показателей и экспорт результатов в PDF, Excel и CSV.

Для локального запуска требуется Node.js:

```bash
npm install
npm run dev
```

Для сборки проекта:

```bash
npm run build
```

**Примечание:** исторические данные и прогнозные сценарии используются в учебных целях и не гарантируют будущую доходность.
