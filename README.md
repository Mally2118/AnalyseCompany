# InvestAnalytics

Сайт: **https://mally2118.github.io/AnalyseCompany/**.

Статическая инвестиционно-аналитическая платформа для университетского проекта «Бизнес-аналитика и прогнозирование». Объекты исследования — обыкновенные акции ПАО «Сбербанк» (SBER) и МКПАО «Т-Технологии» (T, исторически TCSG), банковские группы по МСФО за 2021–2025 годы.

Проект полностью выполняет расчёты в браузере. Для работы опубликованного сайта не нужны сервер, API-ключ, платный API или доступ к MOEX. Хостинг — **GitHub Pages**. Данные и исходные биржевые свечи включены в репозиторий.

## Доработка расчётов 09.11.2026

Причины расхождений, численные контрольные результаты и выбор второй компании описаны в [аудите](docs/AUDIT-2026-11-09.md). Т-Технологии сохранены. Ценовая и полная доходности теперь используют одинаковые даты и капитал; индивидуальная статистика и Марковиц — одну синхронную месячную выборку. На обзоре отдельно показаны оба CAGR, исторический P/E и предупреждение об ограничении истории. Добавлены ползунок суммы 10 000–1 000 000 ₽ с точным ручным вводом, историческая таблица и график P/E, справочник 12 метрик.

## Комплексная доработка: данные, прогноз и справочник

Подробный отчёт с источниками, годовым примером, ограничениями и списком файлов: [COMPREHENSIVE-UPDATE.md](docs/COMPREHENSIVE-UPDATE.md).

В `financial.json` у каждого поля есть статус: фактическое, расчётное, оценочное или нет данных. Базовая EPS T 2022/2023 подтверждена аудированной МСФО 2023 (прим.18, PDF с.83); рублёвый эквивалент дивиденда USD 0,24/GDR за 2021 найден в МСФО 2021 (прим.28, PDF с.62): 17,82 ₽ до сплита, 1,782 ₽ после. Эквивалент рассчитан при объявлении, фактическое брокерское зачисление неизвестно. Он **не включается автоматически в рыночную полную доходность**, поэтому исходная общая выборка Марковица не меняется.

Расчётная ROA по средним годовым активам — отдельная производная таблица с входами и источниками, а не замена официальной ROA. CIR T остаётся неизвестным из-за неподтверждённого единого состава доходов/расходов. Восстановление методом интерполяции допускается только для одиночного внутреннего пропуска без структурного разрыва. OLS требует ≥12 сопоставимых наблюдений, проверки на последних 25%, R² ≥0,5 и отсутствия экстраполяции. В текущем наборе подходящих пропусков для интерполяции нет, пяти годовых точек для регрессии недостаточно. Оценочные финансовые значения не добавлены и не попадают в Марковица.

Справочник **43 показателей** — `#guide`, прямые ссылки `#guide/cagr`, `#guide/sharpe` и другие. Единый реестр содержит определение, формулу, обозначения, пример, интерпретацию, ограничения и ссылки на страницы. KaTeX и шрифты поставляются локально; backend и CDN не нужны. Значок «?» показывает компактную подсказку с позиционированием внутри экрана: на ПК нажатие ведёт к формуле, на телефоне первое касание открывает подсказку со ссылкой. Поддержаны клавиатура, Escape, поиск, категории и браузерный «Назад». В обзоре есть раскрывающаяся сводка основных/всех показателей без дополнительных графиков.

## Компактный интерфейс

На основном экране обзора — три KPI (прибыль, CAGR, волатильность), один график и краткая оценка компаний. Финансовый раздел показывает два графика и компактную таблицу; дополнительные показатели и исходная отчётность раскрываются отдельно. В риске — четыре KPI и два графика с переключением доходности/просадки. Матрица, формулы и все 101 портфель доступны в «Методика и подробные расчёты». Параметры EPS/P/E/выплат скрыты в «Настроить сценарий», критерии устойчивости и группы источников раскрываются по запросу. Экспорты сохраняют полный объём исследования.

Главный показатель доходности берётся из единой функции `cagr` в `src/calculations/statistics.ts`: `(P1/P0)^(1/n)−1`, где рыночное `n` — фактические дни / 365,25. В интерфейсе результат умножается на 100% форматтером. Формула уже была корректной; повторная реализация не добавлялась. Контрольные примеры 100→121 за 2 года, 100→100 за 5 лет, 100→81 за 2 года дают 10%, 0%, −10% и проверяются автоматически. В Марковице сохранено историческое арифметическое среднее ×12.

```bash
npm run preview
```

## Корпоративные действия и временная сопоставимость

1. TCS Group GDR представляла одну обыкновенную акцию. Редомициляция в 2024 — переход к акции 1:1; историческая цена не умножается произвольно на коэффициент.
2. 28.11.2024 TCSG → T — смена кода. Используется преемственный ряд текущего инструмента из ISS, а не ручная склейка независимых графиков.
3. Текущий endpoint свечей **T уже содержит всю историю, пересчитанную на сплит 1:10**. Цена T повторно на 10 не делится. Проверка по старому TCSG: **975 общих дневных наблюдений**, отношение TCSG/T = 10 с погрешностью < 10⁻⁶.
4. Приобретение Росбанка и допэмиссия в 2024 меняют финансовый периметр и экономику бизнеса; динамику нельзя считать чисто органической. Финансовый CAGR Т по всему периоду не показывается как сопоставимый.
5. Для каждого месяца берётся закрытие **последнего общего торгового дня**. Если этот день раньше конца месяца более чем на семь календарных дней, месяц отсутствует. Семь дней — документированное учебное правило свежести, не правило MOEX.
6. Февраль 2024 исключён из синхронной месячной истории; и февральская, и мартовская доходности пропущены, поскольку отсутствует одна из двух границ интервала. Двухмесячная доходность не становится месячной. На полной пятилетней ценовой базе остаётся **58 пар**. Основная сопоставимая модель обоих режимов использует **46 пар** с конца 2021; период 2023–2025 — **34 пары**.
7. Дневные наблюдения без цены сохраняются как `null`. Значения не переносятся вперёд и не заменяются нулевыми доходностями. Максимальная просадка рассчитывается по имеющимся дневным закрытиям и не учитывает внутридневные минимумы.

## Дивиденды и полная доходность

Ценовой режим не включает дивиденды. Полная стоимость рассчитывается через ежедневную позицию: в документированную дату реестра право на дивиденд условно зачисляется и реинвестируется по закрытию этого дня:

```text
shares_after = shares_before × (1 + dividend_per_share / close_event_day)
wealth_t = shares_t × price_t
monthly_total_return = wealth_month_end / wealth_previous_month_end − 1
```

Так дивиденд не прибавляется второй раз к уже реинвестированному ряду. Допускаются дробные акции. Налоги, комиссии, фактический лаг поступления денег и округление лотов исключены. **Это условная стратегия**, а не фактическая история брокерского счета. При отсутствии проверенных реальных дат поступления не имитируется точный брокерский результат.

SBER: 18,70 ₽ (реестр 2021), 25,00 ₽ (2023), 33,30 ₽ (2024), 34,84 ₽ (2025); в календарном 2022 выплат нет. Год прибыли отличается от года события.

T: расчётный эквивалент 1,782 ₽ за 2021 (не фактическое зачисление), 9,25 ₽ в 2024 и 3,20 + 3,30 + 3,50 = 10,00 ₽ в календарном 2025 после сплита. Дивиденд за III квартал 2025 с реестром января 2026 не включён в историю до конца 2025.

**Ограничение:** USD 0,24/GDR в 2021 подтверждено, но надёжный рублёвый курс зачисления не установлен. Полная доходность T за 2021 не показывается. При выборе 2021–2025 **оба режима и обе компании** используют общую базу **30.12.2021–30.12.2025** (4 года, **46 пар**). Предупреждение видно в обоих режимах. Период 2023–2025 использует базу **30.12.2022–30.12.2025** (1096 / 365,25 года, **34 пары**). Декабрь предыдущего года служит только начальной точкой. Полные пятилетние ценовые CAGR и полный пятилетний CAGR SBER с дивидендами показаны отдельно; пятилетний полный CAGR T — «Нет данных». Переключатель типа доходности не меняет фактические даты. Поэтому положительные дивиденды повышают полную стоимость относительно ценовой на каждой общей дате без искусственной корректировки результата.

## Формулы

Проценты в расчётных модулях хранятся десятичными долями; опубликованные финансовые коэффициенты — в процентах с явной единицей. Сценарные поля роста и payout — проценты, конвертируются при вычислении.

```text
R_t = (P_t − P_(t−1) + D_t) / P_(t−1)
μ_month = average(R)
μ_annual_arithmetic = 12 × μ_month
sample_cov(x,y) = Σ[(x_i − mean_x)(y_i − mean_y)] / (n − 1)
σ_month = sqrt(sample_cov(R,R))
σ_annual = σ_month × sqrt(12)
correlation = sample_cov(x,y) / (σ_x × σ_y)
Rf_month = (1 + Rf_annual)^(1/12) − 1
Sharpe_annualized = (μ_month − Rf_month) / σ_month × sqrt(12)
CAGR = (wealth_last / wealth_first)^(365.25 / elapsed_days) − 1
Drawdown_t = wealth_t / max(wealth_0...wealth_t) − 1
MaxDrawdown = min(Drawdown_t)
VaR95_month = max(0, −quantile_0.05(monthly_returns))
```

Квантиль — линейная интерполяция по отсортированному массиву, индекс `(n−1)×p`, не менее 24 наблюдений. Это историческая однопериодная оценка, не предел убытков. Годовое приведение σ и Sharpe предполагает отсутствие существенной серийной корреляции.

**Sharpe считается на месячном горизонте и затем годится через √12.** Нельзя подставлять эффективную годовую Rf непосредственно в месячный числитель. Поэтому показатель не равен механическому `(12μ_month − эффективная Rf_annual)/σ_annual`.

```text
μp_month = w × μs_month + (1 − w) × μt_month
var_p_month = w² var_s + (1 − w)² var_t + 2w(1 − w) cov_st
```

Годовая ковариационная матрица — месячная ×12. Сетка весов 0…100%, шаг 1%; оптимумы — глобальные по этой сетке, не заявление об аналитическом непрерывном оптимуме. Эффективная точка — недоминируемая по доходности и риску. Минимум риска и максимум Sharpe решают разные задачи.

Средние, риск, Sharpe отдельных акций и ковариация портфеля берутся по одинаковым доступным парам. Крайние веса 0% и 100% совпадают со статистикой соответствующего актива. Экстремальные доходности не удаляются и не ограничиваются. CAGR и просадка используют дневную историю и календарное время, а не произведение неполной месячной выборки. Исторический портфельный CAGR рассчитывается по ежедневной стоимости: веса восстанавливаются в доступные общие концы месяцев, через отсутствующий месяц позиции удерживаются. Он показан рядом с арифметической оценкой.

Для SBER за 2023–2025 `12 × mean` равно 27,54% по цене и 38,83% с дивидендами; календарный CAGR — 28,55% и 42,87%. Эти исходные арифметические результаты были правильны. На полной пятилетней базе арифметические оценки SBER — 8,38% и 16,34%, CAGR — 2,00% и 9,99%. Укороченный период после падения 2022 радикально меняет оценку; ни одна из этих ставок не является гарантией.

## Исторический P/E

`P/E = Price / basic EPS`. Для каждого года 2021–2025 берётся последняя дневная цена с датой не более чем за семь дней до конца года и опубликованная базовая годовая EPS. Цена и EPS T находятся на одной базе сплита 1:10; повторной корректировки нет. Допэмиссия отражается в средневзвешенном числе акций исходной базовой EPS. Операционная EPS не подставляется. При неизвестной или неположительной EPS P/E не выводится положительным числом. Базовая EPS T за 2022–2023 восстановлена по примечанию 18 аудированной МСФО 2023: 105,59/10 = 10,559 ₽ и 405,08/10 = 40,508 ₽. Учтён пересмотр IFRS 17 (2022 ранее 105,81 ₽); это опубликованные значения с корпоративной корректировкой, не регрессия.

Все годовые P/E **ретроспективные**: отчёт опубликован позже цены, поэтому показатель не был доступен инвестору в тот день. Исторический P/E 2025: SBER `299,90 / 77,81 = 3,85`, T `328 / 68,872 = 4,76`. Низкий P/E не доказывает недооценку. Таблица, график и ссылки на цену/EPS находятся в финансовом разделе, базовый P/E также виден в обзоре и прогнозе. Сценарный P/E — самостоятельное редактируемое допущение: при постоянной EPS цена изменяется пропорционально мультипликатору.

## Прогноз 2026 и калькулятор

```text
EPS_2026 = published_basic_EPS_2025 × (1 + earnings_growth)
target_price_2026 = EPS_2026 × scenario_PE
assumed_dividend = EPS_2026 × payout_ratio
scenario_return = (target_price − close_2025 + assumed_dividend) / close_2025
portfolio_return = w × scenario_return_SBER + (1 − w) × scenario_return_T
portfolio_value_one_year = principal × (1 + portfolio_return)
calculator_value_t = sum(shares_company_t × price_company_t + cash_company_t)
```

Ползунок суммы: 10 000–1 000 000 ₽, шаг 10 000 ₽, начальная сумма 100 000 ₽. Поле ручного ввода сохраняет сумму с точностью до рубля; положение ползунка округляется до ближайшего шага, сама сумма при этом не округляется. Второй ползунок задаёт веса. Суммы компаний, сценарии, график и рублёвое заключение получают одну сумму и одни веса.

**Режим А (2026):** исходная модель EPS × P/E сохранена. **Режим Б (2–10 лет):** EPS, P/E, payout и коэффициент сплита заданы отдельно на каждый год. Первоначальная EPS 2025 и цена подтверждены, дальнейшие параметры — учебные предпосылки. По умолчанию рост EPS линейно приближается к устойчивому темпу к пятому году: Сбер 0/5/8%, T 5/10/15% в негативном/базовом/позитивном сценариях. Это условная нормализация роста по мере зрелости бизнеса, не оценка, полученная регрессией по пяти точкам. P/E после переоценки 2026 постоянен; все последующие годовые параметры редактируются в «Годовые предпосылки».

Позиции между компаниями не ребалансируются. Дивиденды по выбору реинвестируются в конце года или накапливаются деньгами без процентов. При реинвестиции выплата увеличивает число акций и не прибавляется повторно к деньгам. Сплит взаимно меняет EPS и акции; допэмиссия не моделируется как сплит. Годовая доходность первого года **не повторяется**. Исторический портфельный CAGR использует свою описанную стратегию ребалансировки; эти стратегии подписаны раздельно.

```text
EPS_t = EPS_(t-1) × (1 + g_t) / split_t
Price_t = EPS_t × PE_t
Shares_after_split = Shares_previous × split_t
Dividend_cash_t = Shares_after_split × EPS_t × payout_t
Reinvest: Shares_t = Shares_after_split + Dividend_cash_t / Price_t; Cash_t = 0
Cash: Shares_t = Shares_after_split; Cash_t = Cash_(t-1) + Dividend_cash_t
Value_t = Σ(Shares_t × Price_t + Cash_t)
Forecast_CAGR = (Value_n / Value_0)^(1/n) − 1
```

Контрольный пример 500 000 ₽, 100% T, пять лет, позитивный сценарий: старое повторение 106,93096% давало **18 971 313,59 ₽**; новая годовая модель даёт **2 744 272,39 ₽** с реинвестированием (CAGR 40,5696%) и **2 570 018,79 ₽** с накоплением выплат деньгами. Ни один результат не ограничивается искусственным пределом. При превышении исторического CAGR более чем на 10 п.п. показано нейтральное сообщение: 10 п.п. — учебный порог чувствительности, не статистическая вероятность. Воспроизведение: `npx tsx scripts/audit-projection.ts`, JSON — [T-five-year-audit.json](docs/examples/T-five-year-audit.json).

Исходные цена и EPS подтверждены. Рост EPS, P/E и payout — редактируемые предпосылки, не рыночный консенсус и не оценка гарантированной справедливой стоимости. Сценариям не приписываются вероятности.

Отчётность 2025 опубликована в 2026. Поэтому это **ретроспективная учебная модель**, а не честный прогноз, который мог быть составлен 31.12.2025. Фактические показатели и котировки 2026 не используются. Возможны разовые эффекты прибыли, допэмиссия, изменение дивидендов, санкций, ставки и кредитного качества.

## Устойчивость

Шесть равноправных сигналов: прибыль > 0; капитал не снижается; ROE ≥15%; общий капитал ≥12%; NPL / стадия 3 ≤6%; прибыль не снижается. Отсутствует ключевой показатель — «Недостаточно информации». Прибыль/капитал ≤0 или минимум три отрицательных сигнала — «Неблагоприятная динамика»; один-два — «Повышенные риски»; ни одного — «Относительно устойчивое».

Риск акции: высокий при годовой σ ≥35% или дневной просадке ≥40%; умеренный при σ ≥20% или просадке ≥20%, если нет высокого риска; иначе низкий. Все пороги учебные и объяснены в интерфейсе; это не нормативы ЦБ и не кредитный рейтинг.

Определения NPL, ROE и достаточности капитала различаются. Число сигналов не доказывает превосходство кредитоспособности. Падение акции, временный убыток, дефолт и прибыль различаются. Банкротство по пяти годовым наблюдениям не предсказывается. Отрасль из двух банковских групп не обеспечивает широкую диверсификацию.

## Обновление данных

Исторический диапазон намеренно фиксирован на 2021–2025. Автоматическое расписание не настроено: пересмотр финансов и корпоративные действия требуют проверки.

```bash
npm run data:update
```

Скрипт использует `candles.json` TQBR, `interval=24` (день), `start` для всех страниц. Он проверяет структуру ответа, перекрытие TCSG/T, отношение масштабов, начальные якоря, полноту и наличие цены в даты дивидендов. Запросы последовательные с паузой 350 мс, тайм-аутом и максимум тремя попытками. CORS проверяется реальным GET с Origin, в сохранённом аудите сервер вернул разрешённый Origin. Браузерный клиент ISS не вызывает.

Кандидат сохраняется в **`.data-candidates/` вне публикуемого `public/`**. Текущая успешная версия не заменяется при сетевой ошибке или нарушении валидации. После ручной проверки кандидата:

```bash
node scripts/update-market.mjs --accept
npm run data:validate
npm test
npm run build
```

Новая версия и raw-выгрузка устанавливаются после успешного получения всех данных; при ошибке финального переключения raw-каталог восстанавливается. Для первичной разработки эти команды уже выполнены; для запуска проекта обновлять историю не нужно.

Финансовые поля обновляются вручную по первичным PDF с сохранением `sourceId`, страницы, стандарта, причины пересмотра и признака сопоставимости. Включение 2026 в рыночную историю потребует новой спецификации периода и тестов сплита; нельзя просто поменять `till`.

Доступность ISS не равна лицензии на коммерческое распространение данных. Набор предназначен для ознакомительного университетского исследования. Для иных способов использования проверьте [условия MOEX](https://www.moex.com/a2193). Гарантированный публичный лимит запросов в рассмотренной документации не установлен; 350 мс — ограничение этого скрипта, не объявленный лимит биржи.

## Публикация на GitHub Pages

1. Создайте обычный GitHub-репозиторий, загрузите все файлы проекта, включая `package-lock.json` и `public/data/`. Для бесплатных Pages используйте публичный репозиторий.
2. Откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Отправьте изменения в `main` или `master`, либо запустите workflow **«Проверка и публикация GitHub Pages»** вручную.
4. Дождитесь успешного задания `deploy`. URL будет в разделе Pages и в выводе workflow: `https://<пользователь>.github.io/<репозиторий>/`.

Workflow выполняет `npm ci`, валидацию данных, математические тесты, `npm run build`, production-тесты Chromium и только затем публикует `dist`. Секреты настраивать не требуется: используются стандартные разрешения `GITHUB_TOKEN` для Pages и OIDC. Для pull request есть отдельный workflow проверки без публикации.

`base: './'` формирует относительные ресурсы. Загрузка JSON, регистрация service worker и ссылки на данные учитывают `import.meta.env.BASE_URL`. Навигация через `#overview`, `#portfolio`, `#forecast` не требует серверного fallback или 404-хаков; название репозитория может быть любым. Проверка выполняется на пути `/arbitrary-repository/`, а не только в корне localhost.

После первого полного кэширования можно перезагрузить production-сайт без сети. Service worker применяется только к своей папке, версия кэша зависит от содержимого всей сборки; сайт из другого репозитория не затрагивается. В dev-режиме SW не регистрируется.

Для репозитория [Mally2118/AnalyseCompany](https://github.com/Mally2118/AnalyseCompany) включена публикация через GitHub Actions. Адрес сайта: https://mally2118.github.io/AnalyseCompany/. Каждый push в `main` запускает проверки и публикацию; результат доступен в [Actions](https://github.com/Mally2118/AnalyseCompany/actions).

Официальные инструкции: [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite static deployment](https://vite.dev/guide/static-deploy.html).

## Проверки

```bash
npm run data:validate
npm test
npm run build
npx playwright install chromium --only-shell
npm run test:e2e
npm audit
```

В Linux для установки браузерных зависимостей: `npx playwright install --with-deps chromium --only-shell`. Альтернатива для уже установленного совместимого Chromium: переменная `PLAYWRIGHT_EXECUTABLE_PATH` с абсолютным путём к исполняемому файлу.

Playwright проверяет переключатели, страницы, изменение весов и прогнозов, экспорт в настоящие файлы, мобильную тему и офлайн-перезагрузку production-сайта в подкаталоге.
